# キーボードショートカット

ショートカットは macOS では `⌘`、Windows と Linux では `Ctrl` です。

## ペイン

| ショートカット | 動作 |
| --- | --- |
| `⌘D` | フォーカス中のペインを横に分割 |
| `⌘⇧D` | フォーカス中のペインを縦に分割 |
| `⌘⇧W` | フォーカス中のペインを閉じる |
| `⌘⌥` + `←` `→` `↑` `↓` | その方向のペインへフォーカスを移す |

## タブ

| ショートカット | 動作 |
| --- | --- |
| `⌘T` | 新しいタブ |
| `⌘N` | 新しいタブ |
| `⌘R` | 現在のタブをリネーム |
| `⌘W` | 現在のタブを閉じる |

## 検索とナビゲーション

| ショートカット | 動作 |
| --- | --- |
| `⌘⇧F` | 全プロジェクト横断のグローバル検索 |
| `⌘F` | 現在のビュー内を検索 |
| `⌘G` | 次のヒット |
| `⌘⇧G` | 前のヒット |

## ビュー

| ショートカット | 動作 |
| --- | --- |
| `⌘B` | サイドバーの表示切り替え |
| `⌘⇧B` | git の変更をタブとして開く |
| `⌘J` | サイドチャットの切り替え |
| `⌘K` | ツール管理 |
| `⌘⇧S` | 統計 |
| `⌘⇧T` | ゴミ箱 |
| `⌘,` | 設定 |

## 操作

| ショートカット | 動作 |
| --- | --- |
| `⌘O` | 現在のフォルダをブックマーク |
| `⌘E` | 開いているセッションを Markdown で書き出す |

内蔵ターミナル内では、`⌘W`・`⌘T`・`⌘R`・`⌘F` はターミナルのタブ側が自分で処理し、シェルへは渡しません。
