# 键盘快捷键

macOS 上用 `⌘`，Windows 和 Linux 上用 `Ctrl`。

## 分屏

| 快捷键 | 动作 |
| --- | --- |
| `⌘D` | 把当前 pane 横向切开 |
| `⌘⇧D` | 把当前 pane 纵向切开 |
| `⌘⇧W` | 关闭当前 pane |
| `⌘⌥` + `←` `→` `↑` `↓` | 焦点移到那个方向的 pane |

## 标签

| 快捷键 | 动作 |
| --- | --- |
| `⌘T` | 新建标签 |
| `⌘N` | 新建标签 |
| `⌘R` | 重命名当前标签 |
| `⌘W` | 关闭当前标签 |

## 搜索与导航

| 快捷键 | 动作 |
| --- | --- |
| `⌘⇧F` | 跨所有项目的全局搜索 |
| `⌘F` | 在当前视图内搜索 |
| `⌘G` | 下一个命中 |
| `⌘⇧G` | 上一个命中 |

## 视图

| 快捷键 | 动作 |
| --- | --- |
| `⌘B` | 开关侧栏 |
| `⌘⇧B` | 把 git 改动作为标签打开 |
| `⌘J` | 开关侧边对话 |
| `⌘K` | 工具管理 |
| `⌘⇧S` | 统计 |
| `⌘⇧T` | 回收站 |
| `⌘,` | 设置 |

## 操作

| 快捷键 | 动作 |
| --- | --- |
| `⌘O` | 把当前文件夹加入书签 |
| `⌘E` | 把当前会话导出成 Markdown |

在内嵌终端里，`⌘W`、`⌘T`、`⌘R`、`⌘F` 由终端标签自己处理，不会透传给 shell。
