# 工具管理

[English](README.md) · **中文** · [日本語](README.ja.md)

每个 agent CLI 都把自己的 skills、MCP 服务器、hooks 和指令文件存在磁盘的某个角落。装几个工具、换着用几个月，就没人说得清现在到底加载了什么。同一个 skill 在三个目录里各有一份，某条链接指向的东西早被删了，某个只配过一次的服务器还在你已经忘掉的那个 agent 里跑着。

工具管理面板把它们摊在一起，并且让你能动手收拾。入口在侧栏底部的扳手图标，或者按 `⌘K`。

## 完整文档已迁移

带每个面板截图的完整说明，现在放在文档站的源文件里：

**→ [工具管理文档](https://sessions-viewer.js-bridge.com/zh/tools/)**

内容包括：

- Skills：重复 / 绕路 / 死链的体检结果，每个 skill 的内容与引用、风险点，搬进主 store、修链接，以及一次删掉所有副本
- MCP 服务器：七家 agent 的服务器汇总、按 token 计的上下文预算、哪几家在跑它，以及默认打码的密钥
- 发现 skills：搜 skills.sh，装之前先把 skill 看清楚
- Hooks：按命令归并，可以用真实 payload 试跑
- 全局配置：`CLAUDE.md`、`AGENTS.md`、它们 import 进来的文件，以及同名文件之间的漂移
- 配置集：导出你这套配置，但不带任何值

有两条规则始终成立。不确认就不写盘，每个操作都先把会改哪些文件摆出来。不动你已有的内容，因为只重写本应用自己那几个键，原文件在旁边留一份备份。
